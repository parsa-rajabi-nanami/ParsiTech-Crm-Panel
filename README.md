# ParsiReach — پیامک خودکار سفارش‌های ووکامرس

افزونه با تغییر وضعیت سفارش، پیام پترن IPPanel را به شماره موبایل سفارش می‌فرستد. هر اتوماسیون وضعیت آغاز، کد پترن، متغیرها، تأخیر پیام نخست، تعداد کل ارسال‌ها و فاصله میان پیام‌ها را تعیین می‌کند.

## نیازمندی‌ها

- WordPress 6.4 یا جدیدتر
- PHP 8.1 یا جدیدتر
- WooCommerce 7.9 یا جدیدتر
- API Key از بخش Developers → Access Keys در IPPanel و خط فرستنده مجاز

## نصب و راه‌اندازی

1. افزونه را نصب و فعال کنید.
2. در **ParsiReach ← تنظیمات پیامک**، API Key خام را وارد کنید؛ `Bearer` به ابتدای آن اضافه نکنید. شماره خط مجاز را نیز وارد و تنظیمات را ذخیره کنید.
3. ابتدا Sandbox را روشن نگه دارید و اتصال را بررسی کنید. برای ارسال واقعی Sandbox را خاموش و سرویس را فعال کنید.
4. در صفحه اتوماسیون‌ها وضعیت شروع، تأخیر، کد پترن، مقادیر JSON، تعداد کل ارسال‌ها و فاصله تکرار را تنظیم کنید.

## روند اجرای اتوماسیون

با تغییر وضعیت سفارش، افزونه وضعیت‌های ثبت‌شده در ووکامرس را با اتوماسیون‌های فعال تطبیق می‌دهد. برای هر تطبیق، یک کار یکتا در صف می‌سازد و آن را پس از تأخیر تنظیم‌شده اجرا می‌کند. Action Scheduler ووکامرس صف را اجرا می‌کند و در نبود آن، افزونه از WP-Cron استفاده می‌کند.

هنگام اجرا، فعال بودن اتوماسیون، وضعیت فعلی سفارش و شماره موبایل دوباره بررسی می‌شوند. سپس متغیرهای پترن از اطلاعات سفارش پر می‌شوند و درخواست به IPPanel فرستاده می‌شود. پس از پذیرش درخواست، اگر تعداد ارسال‌ها کامل نشده باشد، پیام بعدی به فاصله تعیین‌شده زمان‌بندی می‌شود. خطاهای موقت حداکثر سه بار با فاصله افزایشی تلاش می‌شوند. گزارش موفقیت به معنی پذیرش درخواست در پنل است و وضعیت تحویل به گوشی در این نسخه دریافت نمی‌شود.

برای اجرای به‌موقع صف، در سایت‌های کم‌ترافیک، اجرای زمان‌بندی‌شده واقعی سرور برای `wp-cron.php` را پیکربندی کنید.

## متغیرهای پترن

یک شیء JSON وارد کنید که کلیدهای آن با متغیرهای تعریف‌شده در پترن IPPanel برابر باشد. مقدارها می‌توانند از توکن‌های زیر استفاده کنند:

`{customer_name}`, `{customer_last_name}`, `{order_number}`, `{order_date}`, `{order_total}`, `{product_name}`, `{shop_name}`

## گزارش‌ها و حذف داده‌ها

گزارش‌ها را می‌توان فیلتر کرد، موارد انتخاب‌شده یا همه گزارش‌ها را حذف کرد و کارهای ناموفق را دوباره در صف گذاشت. با حذف افزونه، تنظیمات، صف‌ها، گزارش‌ها، جداول و داده‌های مختص افزونه از پایگاه داده پاک می‌شوند.

کلید API به‌صورت رمزنگاری‌شده با WordPress salts ذخیره می‌شود. تغییر salts ممکن است مانع رمزگشایی کلید ذخیره‌شده شود؛ در این حالت کلید را دوباره وارد کنید.
